# AstroVeda - Guidance Written in the Stars 🌟
### Static Astrology Consultation Web Application Prototype

AstroVeda is a high-converting, luxury spiritual-tech client demonstration prototype built for astrology consultation platforms.

---

## 🚀 How to Run

1. Open `index.html` directly in any web browser (Chrome, Safari, Firefox, Edge).
2. No build tools, `npm`, Node.js, or server setup is required.

---

## 🎯 Demo Mode Role Switcher

Use the persistent floating bar at the top of the browser screen to switch between:

1. **User App**: Full user journey from Onboarding, Home, Horoscope, Astrologer Marketplace, Detailed Profile, Real-time Chat Consultation (with live timer & spent tracker), Audio Call, Video Call, Kundli SVG Generator, Wallet Recharge, Reports Store, and Review Ratings.
2. **Astrologer Portal**: Dashboard with online status toggle, earnings analytics, incoming call simulator trigger, and withdrawal management.
3. **Admin Panel**: Executive dashboard with KPI summary cards, platform revenue breakdown, user status toggles (Block/Unblock), and astrologer withdrawal request approvals.

---

## 🎨 Technology & Design System

- **HTML5 & CSS3**: Vanilla design system with CSS custom properties.
- **Bootstrap 5 & Bootstrap Icons**: Responsive grid, modals, carousels, and icons.
- **Vanilla JavaScript**: Dynamic view routing, live timer algorithms, wallet updates, search filtering, chat auto-responder, and SVG Kundli wheel rendering.
- **Color Palette**:
  - Midnight Navy (`#17132f`)
  - Deep Purple (`#7656b8`)
  - Warm Gold (`#d6ad5b`)
  - Cream (`#faf7f0`)
